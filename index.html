🤖

AI-Powered Operations

Integrated LLM model enables autonomous reconnaissance, system analysis, and intelligent task execution without operator intervention.

🚀

High Performance

Built with Go for exceptional performance and cross-platform compatibility. Supports Windows, Linux, and macOS on both x86_64 and ARM64 architectures.

🔒

Security Features

Memory-based operations with MemDB, configurable logging, and customizable sleep intervals with jitter for operational security.

🌐

Flexible Communication

HTTP/HTTPS transport with AES-256-GCM encryption, configurable jitter, and custom user agents.
